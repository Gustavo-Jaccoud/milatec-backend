ÁREA DO CLIENTE E ADMINISTRADOR
SISTEMA MILATEC COM INTEGRAÇÃO VIA API E AIRTABLE

1. Objetivo

Este documento define, de forma estruturada, quais informações serão disponibilizadas no sistema para os clientes da MilaTec e quais serão restritas ao uso administrativo.

O sistema será um painel de visualização e acompanhamento, centralizando informações de obras, projetos e entregas, com foco em transparência para o cliente e controle interno.

O sistema não permitirá alterações diretas, funcionando exclusivamente como espelhamento do Airtable, garantindo consistência e uma única fonte de verdade.

2. Princípios Gerais

Sistema com acesso somente leitura
Airtable como fonte única de dados
API responsável pela leitura e organização das informações
Separação entre visão do cliente e visão administrativa
Exposição controlada de dados sensíveis
Controle de acesso por perfil

2.1 Estrutura de Navegação

O sistema deverá permitir acesso direto às seguintes interfaces:
Funil de Obras
Funil de Projetos
Programação de Entregas

Cada interface organiza as informações em um contexto específico:

Funil de Obras
Apresenta a visão geral das obras e orçamentos, servindo também como base para navegação para projetos e entregas.

Funil de Projetos
Focado no detalhamento dos projetos, incluindo informações técnicas, produtos e valores.
Programação de Entregas
Voltada para o acompanhamento das entregas, com foco em datas, etapas e faturamento.

2.2 Navegação entre Módulos

O sistema deve permitir navegação entre as entidades relacionadas:
Obra → Projetos → Entregas
Projeto → Obra
Entrega → Obra

Essa navegação deve ocorrer de forma fluida.

4. VISÃO DO ADMINISTRADOR MILATEC

O administrador terá acesso completo para fins de acompanhamento e gestão, sem possibilidade de edição.

Diferente do cliente, que visualiza apenas os dados da sua própria empresa, o administrador terá acesso a toda a base de clientes, podendo visualizar informações de todas as empresas cadastradas no sistema.

Essa é a principal diferença entre os perfis de acesso.

9. Funcionalidades Avançadas (Desafio)

Este tópico apresenta algumas ideias de evolução do sistema, focadas em automação de processos que hoje são manuais e sujeitos a erro.

9.1 Validação de Nota Fiscal com IA

Uma das possibilidades é a utilização de uma IA para leitura automática das notas fiscais em PDF anexadas no Airtable. Nesse cenário, o sistema extrai informações como o valor total da nota e realiza a comparação com o valor preenchido manualmente na entrega.

Com isso, torna-se possível identificar de forma automática se os dados estão corretos ou se existe alguma divergência. Dessa forma, o processo de conferência se torna mais ágil e menos suscetível a erros.

9.2 Conversão de Romaneio (.xlsm → PDF)

Outra melhoria seria a conversão automática dos romaneios. Atualmente, esses arquivos são anexados em formato .xlsm, o que dificulta a visualização e o acesso.

A proposta é que o sistema realize a conversão para PDF de forma automática, permitindo que o documento já esteja disponível para visualização diretamente no sistema, sem necessidade d

e download ou uso de ferramentas externas. Isso torna o acesso mais simples e padronizado.

10. CONSIDERAÇÕES FINAIS

O sistema atuará como um painel de visualização estruturado, com foco em organização, transparência e segurança.

Todas as alterações continuarão sendo realizadas no Airtable, garantindo consistência dos dados e redução de complexidade no sistema.
